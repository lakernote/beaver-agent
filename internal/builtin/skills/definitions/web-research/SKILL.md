# Web research

1. 用 `web_search` 搜索；query 保留用户问题中的实体、版本和时间范围。结果只是线索，摘要不能当作事实。
2. 技术问题优先选官方文档、官方 API、源代码仓库和原始论文；用 `web_fetch` 读取最相关的 1–3 个页面。读取失败就换下一个候选，或换关键词再搜一次。
3. 可能变化的信息要核对页面里的发布日期；重要结论尽量用两个独立网站交叉验证。
4. 只把实际读取并支持结论的页面列为来源，附完整 URL；不伪造链接。页面没有提供所需信息时如实说明，不用常识补猜。
5. 先回答问题，再列关键证据和仍不确定的部分。
